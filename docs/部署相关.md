# 部署/初始化（KBMS 必需组件）

知识库管理系统（KBMS）需要：
- PostgreSQL（datasets/documents/segments 等元数据与文本）
- Qdrant（向量库）
- Redis（可选：网关任务/缓存等；KBMS 不强依赖，但推荐启动）

## 一键启动（推荐）

使用 `docker-compose.kbms.yml`：

```bash
docker compose -f docker-compose.kbms.yml up -d
```

## 手动启动（Windows CMD 示例）

### PostgreSQL

```bat
docker run -d --name my-pg ^
  -e POSTGRES_PASSWORD=111111 ^
  -p 5432:5432 ^
  -v pg-data:/var/lib/postgresql/data ^
  --restart unless-stopped ^
  postgres:latest
```

### Qdrant（务必映射端口）

> 常见问题：Qdrant 没有 `-p 6333:6333` 会导致上传/入库卡住或失败。

```bat
docker run -d --name my-qdrant ^
  -p 6333:6333 ^
  -p 6334:6334 ^
  -v qdrant-data:/qdrant/storage ^
  --restart unless-stopped ^
  qdrant/qdrant:latest
```

### Redis（可选）

```bat
docker run -d --name my-redis ^
  -p 6379:6379 ^
  -v redis-data:/data ^
  --restart unless-stopped ^
  redis:latest redis-server --appendonly yes --requirepass 111111
```

## 数据库建表/初始化

KBMS / 服务注册 / 会话 等都依赖 `database/schema.sql` 的表结构。

- 默认会在网关启动时自动检测并初始化（`GATEWAY_DATABASE__AUTO_INIT=true`）
- 如需手动执行（或排查问题）：`python scripts/init_database.py`

## 文档格式支持

后端支持：`txt` / `md` / `pdf` / `docx` / `url`

- 旧版 Word `.doc`（OLE 格式）暂不支持，请先另存为 `.docx`。

## 依赖安装

PDF/DOCX/URL 解析依赖已加入 `requirements.txt`：

```bash
pip install -r requirements.txt
```

## 快速自检

- PostgreSQL：能连上 DSN（见 `config/env.local` / `config/.env`）
- Qdrant：`curl http://localhost:6333/collections` 返回 200
- 网关：`GET http://localhost:8080/api/v1/knowledge/datasets` 返回列表

# 企业级AI服务监控仪表盘设计方案

**日期**: 2026-01-15
**状态**: 已确认，待实现

## 一、需求概述

### 目标
打造Grafana风格的企业级AI服务监控可视化仪表盘，支持内部调用和外部API的统一监控。

### 核心需求
1. **风格**: Grafana风格 - 面板式布局、运维导向、高度可定制
2. **监控模块**: 服务健康、成本分析、性能监控、Token用量、链路追踪、安全审计、用户配额
3. **来源区分**: 内部调用（AI助手、智能对话）vs 外部API调用
4. **刷新策略**: 定时刷新（30秒/1分钟）
5. **告警**: 暂不实现
6. **实现方式**: 增强现有React Dashboard

## 三、数据来源区分方案

### 后端扩展
扩展 `/api/v1/usage` 端点，增加 `source` 筛选参数：
- `source=internal` → AI助手 + 智能对话
- `source=external` → 外部API调用
- `source=all` → 全部（默认）

### 前端筛选器
```
┌─────────────────────────────────────┐
│  来源:  [全部 ▼]  [内部调用]  [外部API]  │
└─────────────────────────────────────┘
```

### 展示逻辑
- 选择"全部"时：合并展示，但用颜色/标签区分来源
- 选择"内部调用"时：只显示AI助手+智能对话的数据
- 选择"外部API"时：只显示外部用户通过API Key调用的数据

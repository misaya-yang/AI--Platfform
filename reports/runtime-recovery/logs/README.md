# DR-01 execution logs

These are captured outputs from actual local commands. The committed text copies
remove ANSI color sequences and trailing whitespace only; command results,
counts, failure messages and source/image identities remain unchanged.
Original unformatted captures are retained locally under
`tmp/runtime-durable-recovery/` (ignored, not committed).
C3/C4 and failed/interrupt traces are named separately. Current short
pre-integration checks use `merge-*.log`; they do not represent another provider
or full crash-matrix run.
